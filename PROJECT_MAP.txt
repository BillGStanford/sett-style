  SERVICES/API — BACKEND

  ── main.py ─────────────────────────────────────────────────────
    FastAPI entry point. Registers all routers, middleware, lifespan.
    If you add a new domain: create the domain folder + add router here.

  ── core/ (shared infrastructure) ───────────────────────────────

  core/config/settings.py
    All environment variables as typed Pydantic Settings.
    extra="ignore" means NEXT_PUBLIC_ vars won't crash the backend.
    If you add a new env var: add field here + add to both .env files.

  core/database/connection.py
    asyncpg connection pool. init_db() called at startup.
    If DB connection fails: check DATABASE_URL in services/api/.env.

  core/auth/dependencies.py
    FastAPI auth dependencies: get_current_user, get_optional_user.
    Extracts user ID from JWT sub claim WITHOUT signature verification.
    Trusts Supabase to have already validated the token.
    Auto-creates user row on first Supabase OAuth login.
    If 401 errors appear: debug this file first.

  core/auth/jwt.py          — Our own JWT creation (used for email/password login)
  core/cache/redis_client.py — Redis cache helpers (cache_get, cache_set)
  core/logging/logger.py    — structlog setup
  core/storage/r2.py        — Cloudflare R2 upload/delete/presign

  ── domains/ (product domains) ──────────────────────────────────

  Each domain has: routes.py (HTTP handlers) + service.py (business logic) + schemas.py (request/response types)

  domains/users/
    routes.py   — POST /register, POST /login, GET /me, PATCH /me, POST /@{username}/follow
    service.py  — User CRUD, password hashing, follow/unfollow
    schemas.py  — UserCreateSchema, UserProfileSchema, TokenResponseSchema, etc.
    
    If you add a user field: add to migrations/001_initial_schema.sql + schemas.py + service.py.

  domains/items/
    routes.py   — POST /clip, POST /upload, GET /, GET /{id}, DELETE /{id}
    service.py  — URL domain lookup, affiliate URL wrapping
    schemas.py  — ItemClipSchema, ItemResponseSchema
    processor.py — Background removal pipeline (rembg). Runs async.
    
    If clipping fails: debug processor.py. Check rembg is installed.
    If affiliate links are wrong: debug service.py _wrap_affiliate_url().

  domains/sets/
    routes.py   — GET /feed, GET /featured, POST /, GET /{id}, GET /{id}/items,
                  PATCH /{id}, POST /{id}/like, POST /{id}/remix
    service.py  — Feed query, create/update sets, like toggle, remix
    schemas.py  — SetCreateSchema, SetResponseSchema, SetFeedSchema

  domains/canvas/
    routes.py   — GET /{id} (load), PATCH /{id}/autosave, POST /thumbnail-upload-url

    Autosave calls PATCH /canvas/{id}/autosave every 60 seconds.

  domains/commerce/

    schemas.py  — CreatorEarningsSchema, ClickResponseSchema

    Every "Shop" button in the frontend routes through GET /commerce/click/{itemId}.
    This records the click server-side then redirects to the affiliate URL.
    If earnings are wrong: debug service.py process_conversion().

  domains/referrals/

  ENVIRONMENT FILES — WHAT GOES WHERE
  ═══════════════════════════════════════════════════════════════

  apps/web/.env.local          ← FRONTEND ONLY
    NEXT_PUBLIC_API_URL         Next.js fetch base URL (exposed to browser)
    NEXT_PUBLIC_SUPABASE_URL    Supabase project URL (exposed to browser)
    NEXT_PUBLIC_SUPABASE_ANON_KEY  Supabase anon key (exposed to browser — safe)

  services/api/.env            ← BACKEND ONLY
    DATABASE_URL                PostgreSQL connection string
    SUPABASE_URL, SUPABASE_ANON_KEY, SUPABASE_SERVICE_KEY, SUPABASE_JWT_SECRET
    SECRET_KEY                  Random hex string for our own JWTs
    CORS_ORIGINS                Must be JSON array: ["http://localhost:3000"]
    R2_*, RESEND_*, STRIPE_*    Optional external services

  DO NOT put NEXT_PUBLIC_ vars in services/api/.env — it crashes pydantic-settings.
  DO NOT put SECRET_KEY or DATABASE_URL in apps/web/.env.local — they'd be exposed.

  COMMON CHANGE RECIPES
  ═══════════════════════════════════════════════════════════════

  "I want to add a new field to the user profile"
    1. services/api/migrations/ → create 00X_add_field.sql, run migrate.py
    2. services/api/domains/users/schemas.py → add field to UserProfileSchema
    3. services/api/domains/users/service.py → update SQL queries
    4. packages/contracts/types/index.ts → add field to UserProfile interface
    5. apps/web/lib/store/auth-store.ts → add field to the interface there too

  "I want to add a new page"
    1. apps/web/app/new-page/page.tsx → create the page
    2. apps/web/components/layout/site-header.tsx → add nav link if needed
    3. apps/web/middleware.ts → add to PROTECTED array if auth required

  "I want to add a new API endpoint"
    1. services/api/domains/{domain}/routes.py → add the route
    2. services/api/domains/{domain}/service.py → add business logic
    3. services/api/domains/{domain}/schemas.py → add request/response schemas
    4. packages/contracts/types/index.ts → add TypeScript types
    5. apps/web/shared/hooks/use-api.ts → add TanStack Query hook

  "I want to change affiliate commission splits"
    services/api/domains/commerce/service.py → change PLATFORM_SHARE / CREATOR_SHARE

  "I want to change the free plan item limit"
    apps/web/features/canvas/components/canvas-editor.tsx → change FREE_ITEM_LIMIT

  "Backend crashes on startup"
    1. Check services/api/.env — no NEXT_PUBLIC_ vars, CORS_ORIGINS as JSON array
    2. Check core/config/settings.py — all vars have defaults
    3. Check core/logging/logger.py — no add_logger_name processor

  "401 Unauthorized on all API calls"
    1. Confirm backend is running: http://localhost:8000/health
    2. Check core/auth/dependencies.py — _extract_sub_from_jwt function
    3. Verify NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_ANON_KEY in apps/web/.env.local

  "Canvas items don't load after clipping"
    1. Check item status in DB (should go processing → ready)
    2. rembg is installed: pip install rembg
    3. Check domains/items/processor.py for errors
    4. R2 credentials needed for images to persist — without them, items disappear on restart

  THIRD-PARTY SERVICES USED
  ═══════════════════════════════════════════════════════════════

  Supabase (auth.supabase.com)
    What: Authentication — manages user sign-up, OAuth, sessions
    Dashboard: https://supabase.com/dashboard/project/ketpewiqjtnvrnltbiap
    Relevant files: lib/supabase/client.ts, lib/supabase/server.ts,
                    shared/components/providers.tsx, middleware.ts,
                    core/auth/dependencies.py

  PostgreSQL (your local pgAdmin)
    What: Primary database
    Connection: postgresql://postgres:DiskCart5@localhost:5432/sett-db
    Schema: services/api/migrations/001_initial_schema.sql

  Cloudflare R2 (optional)
    What: Image storage for item thumbnails and set previews
    Without it: items clip but images don't persist; sets publish without previews
    Relevant files: core/storage/r2.py, domains/items/processor.py,
                    features/canvas/components/publish-modal.tsx

  rembg (local Python package)
    What: Background removal from product images
    Install: pip install rembg
    Downloads U2Net ONNX model (~85MB) on first use
    Relevant file: services/api/domains/items/processor.py

  Stripe (optional — for Pro subscriptions)
    What: $9.99/month Pro plan payments
    Relevant files: services/api/domains/commerce/routes.py (subscribe/pro endpoint),
                    apps/web/app/settings/page.tsx (upgrade button)
